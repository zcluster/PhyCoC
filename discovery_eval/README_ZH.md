# CoC 试点评估包（v0：三题基线＋三题新压力测试）

这套材料检验两件事：现有案例的 Concept Evolution Graph（CEG）能否经受时间与分支审计；统一评分规则能否用于不同类型的概念转折。首批 SR/CSM/QM 是既有基线题；Maxwell/GR/Wilson RG 是新增的题目设计压力测试，来源核对仍为 `v0`。它不把已预训练模型答出熟悉理论视为历史意义上的独立发现。

## 范围与输入边界

每份 `inputs/` 文件是唯一允许交给待评模型的材料。评分规则、[第二批来源审计](SECOND_BATCH_SOURCE_AUDIT_ZH.md)、原案例和生成的 HTML 都属于评估者材料。六个任务分别冻结，不能把一个案例后续阶段的知识当成另一个阶段的输入。项目现有 [pre-Newton 实验](../../pre_newton_corpus/README.md)已经表明：日期筛选、答案前驱隔离、开放生成和提示式识别要分别报告；这里沿用同一原则。

## 可复现运行方式

1. 为每个任务单独开新上下文，只粘贴对应输入文件。记录模型、版本、采样参数、日期、完整提示和原始输出。不要接入 corpus 检索、网络搜索或其他案例页面。
2. 正式比较优先从首批三题开始；来源审计补齐后再纳入第二批。每个任务运行三种提示条件，每种至少三次独立采样；保持输入事实、最大输出长度和采样参数相同。`direct` 要求候选解释及理由，`linear` 要求按步骤解释，`graph` 要求给出可分支、可汇合的概念状态与转换。各条件均须报告保留的旧结构、一个竞争方案、一个未决问题。
3. 保存原始输出，隐藏模型与条件标签后交给评估者按[评分规则](SCORING_ZH.md)打内容分，再单独审查过程结构；不能替模型改写候选主张和论据。输出格式可能暴露条件，因此报告中要注明这种盲评限制。
4. 逐条记录任何来自冻结时点之后的事实。若模型凭预训练记忆直接写出历史答案，标记为 `recognition-contaminated`；这种输出可以用于测量表达质量，不能计作发现能力。
5. 在同一模型上加入名称与记号改写，再用一个规则明确、历史上不存在的程序化物理世界重复关键转折。名称改写只能减轻显式提示，不能清除预训练记忆；未通过新世界任务时不得把历史题的成功解读为可迁移发现。

三个条件都在输入文件末尾追加以下固定文字之一；不得同时提供评分表：

```text
direct：直接给出你认为最有希望的候选解释及论据。最后分别写出它保留的旧结构、一个竞争方案、一个未决问题。不要先列搜索步骤。

linear：按时间上可行的顺序列出至多四次局部概念修改，每次说明输入、操作和输出。最后分别写出它保留的旧结构、一个竞争方案、一个未决问题。

graph：列出至多四个概念状态和连接它们的转换；允许一个状态分出两个候选，也允许它们汇合。每条转换说明依据和代价。最后分别写出它保留的旧结构、一个竞争方案、一个未决问题。
```

本包目前完成的是**六题设计、模板审计与评分规则试运行**。没有封存的模型运行记录，也没有独立评分者的盲评结果，因此不报告模型通过率或三种提示条件的胜负。第二批的来源审计明确标出尚需原文复核之处；真实模型对比需要按上述协议另行运行。

## 迁移决定

[试点审计](PILOT_AUDIT_ZH.md)给出了首批三例的结构检查和第二批迁移结果；[来源审计](SECOND_BATCH_SOURCE_AUDIT_ZH.md)记录了新增三例的证据强弱与未完成项。41 个规范案例现均已迁入同一 CoC/EG 结构，并在[语料审查记录](../fundamental_physics_discoveries/QA_REPORT.md#coc-expansion-review-in-progress-2026-09-29)中逐案记录内部来源与结构核查。评估包仍只冻结六例，其中三题优先做正式模型比较；模板覆盖不等于原文逐页复核、独立审批或模型发现能力验证。
